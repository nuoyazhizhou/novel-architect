# 概念溯源底座 · 公理前置表（Concept Genesis / Axiom Prelude）

> **定位**：`sp-novel-engine` 的知识底座之一，与 `星火技术预发明时间表.md`（物理器物层前置铺垫）**同构互补**——后者管"东西怎么提前造出来"，本文件管"**理论名词怎么提前让人听懂**"。
>
> **一句话隐喻（来自作者原话）**：林枫的《社会系统协议学》是一座理论大厦，里面大量名词（Agent、Middleware、认证中心、特权环 Ring、跨期终局性、脑裂、技术债、协议栈、Syscall、TCP/UDP、API、哈希、PDCA、看板……）是 **1950–2020 年代才被人类发明/命名**的。若林枫在 1920s 叙事里直接甩这些词，就等于"空降术语 / 机械降神"。**这就像证明一个猜想——你不先完成前置引理（用 1920s 的语言把概念铺一层脚手架），别人（读者/剧中人）怎么知道你的逻辑是怎么推出来的？**
>
> **因此本文件 + Check-9 共同构成「公理前置守门人」**：任何超时代协议学名词，必须在正式点名/升级之前，先以 1920s 的语境、现象、痛点做过类比引入。

## 二、A 类（同期可达，可直接用 1920s 语言引入，无需"未来名词"）

这些概念在 1920 年前后已有人类思想雏形，林枫可以用当时的术语直接讲，不必等"点名升级"：

- **甘特图 / 进度条** —— 亨利·甘特 1910s 已有；可直接用"进度横道图"讲。
- **泰勒科学管理 / SOP / 标准化** —— 1911《科学管理原理》；胡适"八不主义"、白话文运动可作类比（Compiler/Linter 维护者）。
- **复利 / 折现 / 跨期价值** —— 费雪 1930《利息理论》思想同期；可用"银根、长期信用"谈。
- **齐奥尔科夫斯基火箭公式** —— 1903 提出；可同期铺垫。
- **维特根斯坦语义边界** —— 1921《逻辑哲学论》；可直接引用"我语言的边界即我世界的边界"。
- **布尔代数 / 二进制** —— 1847/1854 已有，香农 1937 用继电器实现；1920s 可铺垫但"计算机"概念仍是后来。
- **白话文 / 文字改革** —— 胡适 1917 已发起；**但二简字式压缩过头是反面教材**（见 `案例02_二简字`），须防 hash 碰撞。

> A 类名词**不触发 Check-9**，但 C6（二简字式压缩）仍管文字改革情节。

## 四、Check-9 机检逻辑（与脚本对接）

脚本对单章文本做**脚手架共现检测**：

1. 扫描文本命中的 B 类未来名词（B1–B15）。
2. 对每个命中名词，检查其"1920s 脚手架"关键词是否在**同一章文本**中出现任意一个。
3. 命中脚手架 → 视为已做类比引入 → 该名词 PASS。
4. **未命中任何脚手架 → FAIL（空降术语）**，并报告：
   > `Bx「未来名词」疑似空降术语：缺少 1920s 语境铺垫。建议先以脚手架（…）做类比引入，再点名升级；否则读者/剧中人无法理解其逻辑来源。`

> 设计意图：章节本身就是"前置引理"的承载单元。若作者想在某章正式点名某未来名词，他必须**在该章内**先铺一层 1920s 类比；否则闸门判定为空降，打回补铺垫。跨章前置依赖（如 B5 依赖"单一权威已铺垫"）由哨兵人工核验（Check-9 的 P1 层）。

## 五、总调度编排中的接入点（写前核查）

总调度（dispatcher）在派发"写第 N 章"任务前，应：

1. 查本表 + 时间线总表当前幕，列出**本章计划用到的 B 类未来名词**。
2. 核对这些名词的**脚手架铺垫**是否已在前序章节发生，或**本章计划内包含**类比引入段落。
3. 若前置依赖未满足（如本章要用 B5 脑裂，但"单一权威"铺垫从未出现）→ 先补铺垫章/段，再进入主笔创作。

> 对应作者原话："证明一个猜想，你不完成前置条件，别人怎么知道你怎么证明你的这个逻辑是对的？" —— 概念溯源底座就是把"前置条件"工程化、可机检化。

## 六、跨章状态账本（State Ledger）· 让已解锁公理免重复脚手架

概念在某章完成 1920s 脚手架/解释铺垫并通过 C9 后，运行：

```bash
python skills/sp-novel-engine/scripts/lint_chapter.py <本章.md> --update-ledger
```

该概念即记入插件根 `.local/axiom_ledger.json`（键=名词，值=`{unlocked_in, method}`）。**后序章节直接引用该概念时**，C9 读取账本判 PASS，不再强制本章内重复打比方——既保住"发生学根基"，又不让后文被长类比拖慢节奏。

- 章节标识默认从文件名抽取（如 `第31章-…`），也可用 `--chapter-id 第31章` 显式指定。
- 重置：删除 `.local/axiom_ledger.json` 即可让所有概念回到"需重新铺垫"状态。
- 该账本是"机器记忆"，与人工的"跨章前置依赖核验"（第五节）互补：机器管"是否铺过"，人管"铺得对不对"。
