# 星火小说写作规程引擎 · sp-novel-engine

## Overview
本 skill 是《星火》专属的「写-审-纠-核」规程层。它不代写正文，而是把已有的强约束（主要来自 `C:\git_work\大纲\.cursorrules` 与 `林枫全维战略任务与时间线总表(1920-1949).md`）固化成可机检 + 可人审的 Check-1..10 规则集，供总调度、主笔·天工、协议学哨兵、史官、文笔·修辞五方在每一章落地前过闸。

## 何时使用
- 写新章 / 细化某幕细纲 / 续写
- 改稿体检（历史化、降智、二简字式压缩过头、爽点偏移）
- 跑章节校验：`python scripts/lint_chapter.py <章节.md> [--json] [--outline] [--update-ledger] [--chapter-id 第X章]`

## 四方闭环
```
总调度(墨工) ──编排──▶ 主笔·天工(情节/张力/爽点)
       │                ◀──▶ 哨兵·执宪(死防历史化/降智/压缩过头) [一票否决]
       │                ◀──▶ 史官·司历(蝴蝶效应时间线因果审计)
       │                ◀──▶ 文笔·修辞(去AI味/代入感/show-don't-tell 终判)
       └── sp-novel-engine Check-1..10 对所有产出过闸
```

## 规则集（Check-1..10，明细见 references/linter-rules.md）
- **C1** 本章林枫是否露出协议学工具/论文/白皮书（思想霸权进度）
- **C2** 是否用先知剧透历史日期，还是结构推演引导（降维碾压非意气之争）
- **C3** 1920s 物理阻抗（电力/物流/机床）是否被尊重，有无机械降神
- **C4** 是否与时间线总表当前幕对齐（绝对禁止/必须触发）
- **C5** **历史引力检测**：林枫是否沦为旁观者/小兵 → 触发即判「滑向历史流水账」
- **C6** 二简字式压缩过头：是否粗暴拼音化/口号化，违背 hash 防碰撞
- **C7** 爽点是否仍是「高维协议降维/论文武器库/制度CA竞争」而非江湖暗杀/地摊打仗
- **C8** 八大驱动工具是否在基层叙事落地（喝开水/堆肥/省柴灶/锅驼机的微观剩余）
- **C9** **概念溯源闸门（公理前置）**：B 类超时代名词（特权环隔离/去中介化/认证中心竞争/跨期终局性/脑裂/技术债/协议栈/Syscall/Agent博弈/TCP-UDP/API/哈希/PDCA/看板/MVP 等）出现时，是否已有 1920s 语境铺垫或解释标记——空降术语即判违例（证明猜想需先建前置引理）
- **C10** **文笔质检（去 AI 味/代入感）**：AI 味套路词密度（仿佛/宛如/眸光/嘴角勾起一抹…）与告知式说理词（这说明/意味着/众所周知…）是否偏高；机器只做密度告警，终判交文笔·修辞 agent（视角跳切、感官锚点、对话比等细项由人审）

## 知识底座（引用活体文件，见 references/canon-paths.md）
所有正典与素材**按绝对路径直接读取 `C:\git_work\大纲` 活体文件**，不复制、不老化。首要锚点：`.cursorrules` + `林枫全维战略任务与时间线总表(1920-1949).md`。

## 使用方式
1. 写/改章前，先按 `references/canon-paths.md` 读取当前幕正典。
2. 成稿后跑 `python scripts/lint_chapter.py <章节.md>`，按 EXIT 码与逐条结果修改。大纲/细纲文件自动跳过 C6（或显式 `--outline`）；要固化跨章「公理前置」，在本章铺垫过关后追加 `--update-ledger`。
3. 送哨兵（执宪）做协议学硬审、史官（司历）做因果审计，任一 P0 未过不得交付。

## Resources
### references/
- `canon-paths.md`：活体正典绝对路径索引与加载顺序
- `linter-rules.md`：Check-1..10 详细通过/告警/失败判据
- `concept-genesis.md`：概念溯源底座（超时代名词 → 1920s 脚手架 → 点名幕次 → 前置依赖）

### scripts/
- `lint_chapter.py <章节.md> [--json] [--outline] [--update-ledger] [--chapter-id 第X章]`：启发式过闸脚本，输出每条规定 PASS/WARN/FAIL/SKIP 与退出码（0=无 FAIL，1=有 FAIL）；`--update-ledger` 将本章新铺垫的 B 类概念写入 `.local/axiom_ledger.json` 供后章免重复脚手架

## 红线
- 不代写整章正文；
- 对「历史化/降智/压缩过头」一票否决；
- 一切结论由对应专家出具，本引擎只提供规则与校验。
